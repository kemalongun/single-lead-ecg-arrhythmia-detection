# Single-Lead ECG Signal Acquisition and Visualization

This repository contains code from my undergraduate graduation project, which focused on acquiring and visualizing ECG/heart-rate-related signals using Arduino and Python.

## Project Overview

The project involved a low-cost single-lead ECG setup using Arduino and an ECG sensor module. The uploaded files include Arduino, Processing, and Python scripts used for signal acquisition, basic processing, and visualization.

## Technologies Used

- Arduino
- Processing
- Python
- Matplotlib
- Plotly
- Basic signal processing

## Files

- `ECGArduino.ino`: Arduino sketch for ECG/heart-rate signal acquisition.
- `ECGProcessing.pde`: Processing script for handling or visualizing ECG-related serial data.
- `ECGmatplot.py`: Python script for plotting signal data using Matplotlib.
- `ECGPlotly.py`: Python script for plotting signal data using Plotly.
- `sketch.properties`: Project configuration file.

## Note

This project was developed as an undergraduate graduation project. It is not intended for clinical diagnosis or medical use.
